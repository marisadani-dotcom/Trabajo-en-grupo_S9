## Descripción de los Programas
1. **pila_guiada.py**: Práctica básica de apilamiento y desapilamiento de libros aplicando el concepto LIFO.
2. **reto1_bodega.py**: Sistema de consola para gestión de cajas en bodega con validación de códigos vacíos y duplicados.
3. **pila_acciones.py**: Simulador de editor de texto para registrar y deshacer acciones mediante pilas.
4. **reto2_navegador.py**: Simulador de historial web para retroceder entre páginas visitadas.
5. **cola_guiada.py**: Registro y atención de pacientes en una clínica usando `collections.deque` (FIFO).
6. **reto3_atencion.py**: Sistema completo de turnos y atención al cliente con consultas y control de cola vacía.
